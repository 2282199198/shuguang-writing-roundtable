# 曙光圆桌公众号固定主题包

## 1. 主题包解决什么

这六套主题不是六张“换色皮肤”，而是六种内容气质与信息组件的固定组合。主题选择发生在内容终审之后；它只能改变视觉编码，不能改变事实、观点、限定条件或作者经历。

机器可读配置位于 `assets/wechat-themes/theme-catalog.json`，Image 2.0 原始提示词位于 `assets/wechat-themes/image2-background-prompts.md`，可视化总览位于 `assets/wechat-themes/theme-gallery.html`。

## 2. 自动路由

先看文章承诺读者解决什么问题，再看题材。不要见到一个关键词就机械匹配。

| 主题 | 优先使用场景 | 一句话气质 |
|---|---|---|
| 曙光石墨 `graphite-knowledge` | AI、教育、复杂判断、专业观点、知识长文 | 理性、克制、可信 |
| 晨曦金 `dawn-amber` | 家庭教育、成长、亲子、希望与长期主义 | 温暖、明亮、不煽情 |
| 青墨书院 `ink-academy` | 人文、读书、文化、历史、教育思考 | 安静、书卷、现代水墨 |
| 深海智蓝 `ocean-tech` | AI 科技、商业、产业趋势、数字化 | 清晰、前瞻、信息感 |
| 暖纸手记 `warm-journal` | 个人故事、案例、复盘、随笔 | 真诚、有人味、可亲近 |
| 松石研究所 `sage-lab` | 方法论、教程、清单、工具、研究步骤 | 清楚、实用、方法感 |

混合题材按“读者主要来这里获得什么”处理。例如，同样谈 AI：解释产业变化选深海智蓝；讨论孩子教育的长期判断选曙光石墨；提供 AI 工具操作步骤选松石研究所。

## 3. 固定组件顺序

一篇文章默认只使用以下组件，不要为了丰富而全部堆上：

1. 开篇横幅或核心判断卡：二选一；图片只是增强层。
2. 正文导语：3–7 个短段，尽快交付文章立场。
3. 本文看点：文章超过 2500 汉字且确有三段以上主线时才使用。
4. 章节标题：大号浅色序号、眉题、中文标题构成一组。
5. 小标题：左边线或短题签，只承担第三层层级。
6. 引用/结论块：只放真正值得停顿的判断，全文通常 2–4 个。
7. 列表/步骤：按语义选择圆点或数字，同一组不混用。
8. 结尾收束：给出最后一个可带走的判断，再使用轻量 END 标记。

公众号正文仍遵守 15px 左右正文、1.8 左右行高、三层视觉层级和最多三处高对比点睛。主题色不能成为新的信息层级。

## 4. 背景图片的正确位置

Image 2.0 背景只允许承担以下角色：

- 公众号封面候选底图；
- 正文开篇横幅；
- 极少量章节分隔图；
- 本地预览或选题提案的视觉气氛图。

不要把整篇正文铺在位图背景上；不要让文字可读性依赖图片；不要把本地文件路径、临时生成路径或 `file://` 地址冒充成公众号可发布图片。真实发布前，需要把采用的图片上传到公众号素材库，或完成一次真实粘贴并确认平台已托管图片。

若图片上传失败，删除图片后正文仍必须结构完整、层级清楚。公开粘贴版可保留 `<img>` 作为待上传素材，但交付报告必须标记这一平台验证边界。

## 5. 主题应用步骤

1. 从终审稿中识别文章主承诺、情绪温度、信息密度与主要组件。
2. 从六套主题中选一套；用户指定时服从用户，除非可读性或题材明显冲突，再说明风险。
3. 从目录读取调色板和组件配方；不得同时混入另一主题的卡片、圆角、边框或高亮逻辑。
4. 先输出不依赖背景的单根 `<section>` 粘贴片段。
5. 有合适背景时，追加开篇 `<img>` 或提供独立封面底图；不使用远程占位地址。
6. 生成 390px 手机预览，检查首屏、文字墙、层级、强调竞争和横向溢出。
7. 运行主题目录校验、公众号公开终稿校验和 `gzh-design` 合规校验。

## 6. 维护命令

```powershell
python -X utf8 scripts/validate_theme_catalog.py
python -X utf8 scripts/render_theme_gallery.py
python -X utf8 scripts/wrap_wechat_preview.py --input "正文片段.html" --output "手机预览.html" --title "文章标题"
```

新增或替换图片时，先用 Image 2.0 生成无字、低对比、中心留白的背景，再复制到 `assets/wechat-themes/backgrounds/`，更新目录并重新运行校验。图片生成成功不等于主题已验收；还必须检查窄屏裁切、文字安全区和无图降级效果。
