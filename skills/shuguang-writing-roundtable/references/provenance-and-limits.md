# 设计来源、原创边界与发布限制

本 Skill 最初来自对一组多角色写作产品研究笔记的只读分析。研究材料中的角色协议和系统提示词属于基于公开行为的推测，不是任何产品的官方原文。因此：

1. 把笔记视为产品研究材料，而不是官方规格或可验证的专有提示词。
2. 保留可迁移的机制：中央编排、专业工序、结构化交接、关键决策点、回退、独立事实核查、编辑质量标尺、个人材料与风格接入。
3. 重写角色、术语、协议和质量门，形成“曙光圆桌写作会议”的原创运行框架；不复制原角色姓名或长段提示词。
4. 不声称与“得到大脑”官方产品等价、兼容、合作或获得其内部能力。
5. 不包含也不自动访问得到课程、听书、电子书、内部知识库、账号、授权 Key、归档 API 或一键发布能力。
6. 原始研究笔记不随 Skill 打包，不把私人绝对路径、测试稿或用户内容写入发布包。

## 公开项目的补充启发

2026-08-10 对公开 GitHub 项目做只读调研后，本 Skill 进一步吸收了三类通用方法：

- [Stanford STORM / Co-STORM](https://github.com/stanford-oval/storm)（MIT）：视角引导提问、基于资料继续追问、研究前先构建知识结构，以及人在关键处引导讨论。
- [GPT Researcher](https://github.com/assafelovic/gpt-researcher)（Apache-2.0）：先规划研究问题，再逐项收集、追踪、筛选和汇总来源。
- [Open Deep Research](https://github.com/langchain-ai/open_deep_research)（MIT）：计划后执行、人工检查点、分章节写作与反思。

融合只发生在原创流程层：形成了“视角地图 → 问题树 → 研究回合 → 覆盖门 → 分段反思”的圆桌协议。没有克隆或安装这些项目，没有复制其代码、提示词或界面，也没有引入 LangGraph、CrewAI、爬虫、模型 API 或并行 Agent 依赖。项目的实验指标、来源数量和“无偏”等宣传性主张没有被当作本 Skill 的能力承诺。

CrewAI 的角色编排与自评循环与现有圆桌高度重叠，本轮不再叠加，以避免角色数量增加但决策质量不变。

本公开包只发布原创流程、规则、脚本、合成测试和自有视觉资产。发布与商业分发时继续遵守：

- 复查原材料的使用许可和商标/产品名称表述。
- 保留“基于公开行为研究、非官方实现”的说明。
- 扫描并移除私人路径、凭据、原始笔记、测试稿和用户内容。
- 只宣传已实际验证的能力，不宣称可访问专有内容资产或平台账号。
- 对外名称可使用“曙光圆桌写作会议”，机器标识保持 `shuguang-writing-roundtable`。

这份说明是边界记录，不要求在普通写作任务中展示。只有用户询问来源、对比、发布或授权时才加载并说明。
