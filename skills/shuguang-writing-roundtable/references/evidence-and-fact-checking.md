## 1. 先按用途选择来源

不要使用一条固定的“来源排行榜”解决所有问题。按用途选择：

| 用途 | 首选来源 | 注意 |
|---|---|---|
| 作者经历、立场、独特表达 | 用户本人提供的材料 | 只代表作者，不自动证明外部事实 |
| 数字、日期、制度、产品能力 | 原始文件、官方发布、一手数据 | 核对日期、口径和适用范围 |
| 科研结论 | 原始论文、系统综述、权威专业机构 | 区分相关、因果和证据等级 |
| 历史事件、人物引语 | 原始档案/文本、可信版本、权威研究 | 不把二手转述当原话 |
| 当前新闻、价格、规则、人物职位 | 当前官方来源及可靠报道 | 标注查询日期，检查是否已变化 |
| 概念解释和背景 | 高质量权威二手来源 | 回到原始出处确认关键细节 |
| 写作灵感和线索 | 用户笔记、一般网页、搜索结果 | 只能作为线索，不能直接提升为已证实事实 |

“得到”站内内容只有在当前任务确实提供合法可用内容时，才能作为用户材料或二手来源处理。不得声称本 Skill 天然拥有其课程、听书、电子书或内部知识库访问权。

## 2. 拆分主张

在检索前，把核心命题拆为：

- `fact`：可被证真或证伪的陈述
- `estimate`：依赖模型、样本或假设的估计
- `user_experience`：用户或作者自述
- `opinion`：价值判断或主张
- `inference`：由证据推导出的解释
- `quote`：需要精确出处的原话

只有真正影响文章结论的主张才进入正式台账。过渡句、明显修辞和不影响结论的常识不必制造伪精确工作量。

风险分级：

- 高：错误会伤害读者、改变决策、损害信誉，或涉及金额、健康、法律、政策、身份、重大数字和直接引语。
- 中：错误会削弱论证或造成明显误解。
- 低：背景性、容易纠正且不改变结论。

## 3. 先把主题变成问题

不要拿一个宽泛主题直接搜索，再把结果摘要拼成文章。陌生、复杂、争议或长篇任务先完整读取 [question-led-research.md](question-led-research.md)，建立根问题、视角地图和有优先级的问题树。

检索词来自具体问题和期望证据，而不是只重复主题名。每条资料都要能回到一个问题与一个主张；只能提供灵感但不能支持判断的内容保留为线索，不进入正式证据台账。

## 4. 搜集与停止规则

先搜能直接改变判断的材料，不做漫无目的“多找一些”。

按问题优先级研究，对每条核心主张：

1. 优先寻找一个可定位的一手/官方来源。
2. 一手来源不存在、不可访问或解释性不足时，寻找高质量二手来源。
3. 高风险主张尽量获得独立交叉支持；两篇同源转载只算一个来源组。
4. 观点论证要覆盖关键反例或边界，不要求机械地“每个观点两条素材”。
5. 每轮结束更新问题状态和下一问；只有会改变成稿的缺口才触发追问。
6. 当核心问题已回答或被安全处理，且新来源不再改变表述、范围、置信度、冲突或反例判断时停止，并记录停止原因。

如果用户禁止联网或当前环境无法检索，使用用户材料完成可完成部分，并明确区分“基于所给材料成立”和“外部事实已验证”。

## 5. 评估来源

逐项检查：

- 权威性：发布者是否对该事实负直接责任或具备专业能力？
- 原始性：是否接近原始数据、原文、当事声明或实际规则？
- 时效性：该主题会不会变化，来源是否仍然有效？
- 独立性：不同页面是否都来自同一稿件、数据库或公关材料？
- 可定位性：能否给出 URL、页码、标题路径、段落或时间戳？
- 适用性：样本、地区、人群、时间和定义是否与文中主张一致？
- 激励与偏差：是否是广告、利益相关方、选择性报告或内容农场？

搜索摘要、AI 摘要、聚合页和无来源转述只能帮助定位，不能直接作为关键事实的最终证据。

## 6. 处理用户材料

把本地源目录视为只读，除非用户明确要求修改源文件。保留：

- 文件名或材料 ID
- 标题路径、页码、段落、行号或时间戳
- 原话与转述的区别
- 用户自己的观察与外部事实的区别

用户笔记中的“研究表明”“据说”仍需追到原始出处。找不到时可以写成“我在笔记中记录过一个尚待核实的说法”，但更好的做法通常是删除或降格。

不要把私人材料上传到外部服务，不要记录或传播账号密钥，不要扩大读取范围。

## 7. 写入成稿

选择证据允许的最强、但不过度的措辞：

- `verified`：来源直接、适用且足以支持，可用确定表述。
- `supported`：证据总体支持但有边界，用“研究显示/在某范围内/现有证据支持”等限定。
- `disputed`：可靠来源冲突，呈现分歧和口径。
- `unverified`：不能确认，不作为确定事实。
- `not_verifiable`：个人感受或预测，明确其身份。

精确引语必须核对原文。无法核对时改为忠实转述，不使用引号。数字同时保留时间、单位、分母、地区和定义。

引用要紧邻支持的陈述。用户若要求出版级脚注或特定格式，再按对应规范输出。

## 8. 独立核查

研究完成不等于事实核查完成。事实编辑必须以当前成稿为起点：

1. 重新提取所有可核查陈述。
2. 识别稿件在写作中新增的桥接句、因果词、范围词和绝对化表述。
3. 按风险从高到低验证，不因研究台账标注“可靠”而跳过。
4. 检查引用是否改变原意、数字是否过时、案例是否被过度概括。
5. 输出 `must_fix`、`should_fix`、`unverified` 和简短通过摘要。
6. 修订后对受影响主张重跑，并检查修改是否引入新事实。

事实编辑不评价观点是否新颖，不因不同意作者立场而把观点判为错误。

## 9. 冲突、缺口与高影响主题

来源冲突时记录：各自说法、日期、定义、适用范围、是否同源、可能原因。只有证据足以解释差异时才合并；否则保留 `conflict_unresolved`。

缺少关键证据时依次选择：

1. 缩小范围或加时间/人群限定。
2. 把事实性断言改成作者观点或待检验假设。
3. 删除不影响主线的主张。
4. 请求用户提供材料或授权检索。
5. 若仍会误导，阻止“可发布”结论。

医学、法律、金融、安全及其他高影响主题使用当前权威一手资料并写清适用边界。写作圆桌可以帮助组织表达，但不能把一般信息包装成个体化专业结论。
